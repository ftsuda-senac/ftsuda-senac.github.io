Promise vs. bloqueio síncrono

O problema não é o Promise em si — é rodar lógica demorada de forma síncrona, travando a única thread principal do JavaScript. Os indicadores abaixo (relógio, pulso e botão de clique) provam isso ao vivo: eles só continuam respondendo quando a thread principal está livre.

◐ thread ativa há 0.0s pulso: 0

❌ Sem Promise (bloqueante)

O cálculo pesado roda direto na thread principal. Enquanto ele executa, nada mais no navegador pode acontecer.

function calcularRelatorioSincrono() {
  const inicio = performance.now();
  let soma = 0;

  // trava a thread principal por 3s
  while (performance.now() - inicio < 3000) {
    soma += Math.sqrt(Math.random());
  }
  return soma;
}

btnSync.addEventListener('click', () => {
  const resultado = calcularRelatorioSincrono();
  console.log(resultado); // só loga depois de travar tudo
});

✅ Com Promise (não-bloqueante)

O mesmo cálculo, mas dividido em pequenos pedaços que devolvem o controle ao navegador a cada iteração.

function calcularRelatorioAssincrono() {
  return new Promise((resolve) => {
    const inicio = performance.now();
    let soma = 0;

    function processarPedaco() {
      const inicioPedaco = performance.now();
      while (performance.now() - inicioPedaco < 20) {
        soma += Math.sqrt(Math.random());
      }
      if (performance.now() - inicio < 3000) {
        setTimeout(processarPedaco, 0); // libera a thread
      } else {
        resolve(soma);
      }
    }
    processarPedaco();
  });
}

btnAsync.addEventListener('click', () => {
  calcularRelatorioAssincrono().then((resultado) => {
    console.log(resultado);
  });
});

🧊 V2 — mesma lógica com async/await código ilustrativo, não executado

Mesmo comportamento do painel verde acima (Promise + setTimeout), só que escrito com async/await para comparação. Não tem botão nem está conectado a nada nesta página — é só para ler e comparar a sintaxe.

// V2 — ilustrativo apenas, equivalente ao calcularRelatorioAssincrono() acima
function delay(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function calcularRelatorioAsyncAwait() {
  const inicio = performance.now();
  let soma = 0;

  while (performance.now() - inicio < 3000) {
    const inicioPedaco = performance.now();
    while (performance.now() - inicioPedaco < 20) {
      soma += Math.sqrt(Math.random());
    }
    await delay(0); // libera a thread, igual ao setTimeout(processarPedaco, 0)
  }

  return soma;
}

btnAsync.addEventListener('click', async () => {
  const resultado = await calcularRelatorioAsyncAwait();
  console.log(resultado);
});
Como testar: clique em "Executar cálculo pesado" em cada painel e, enquanto ele roda, tente clicar no botão de teste acima. No painel vermelho, o relógio, o pulso e o botão travam por 3 segundos. No painel verde, tudo continua respondendo normalmente.
